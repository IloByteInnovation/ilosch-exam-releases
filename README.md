# IloSch Exam — downloads

Installers for **IloSch Exam**, the offline CBT app for schools on IloSch:

- **Exam Server**: one PC in the exam hall. It downloads the school's quizzes and pupils from IloSch online, runs the papers with no internet, and sends the papers back when the connection returns.
- **Exam Client**: each exam PC. It finds the server on the school network and shows the exam in a locked full-screen window.

Download the latest installer from **Releases**. To set it up, go to **Settings → Exam Servers** on your school's IloSch site and follow the steps there.

This repository only hosts release files. Each exam-server package is signed, and the app refuses any package without a valid signature.
